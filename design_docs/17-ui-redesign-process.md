# Canvas Power Tools — 17: UI Redesign Process

> **Status: Superseded.**
>
> The per-tool redesign process described in the original version of this document
> guided an AI-directed UI development pass. That approach has been retired.
>
> The new process: design decisions are made by the user in a visual design tool
> (currently Google Stitch), then extracted as named, concrete decisions before
> any code is written. Design docs describe what tools do and what data they
> operate on — not how they look or which UI atoms to use.
>
> When the Stitch designs are finalized, a new design token spec and component
> vocabulary will be derived from them and documented here.
